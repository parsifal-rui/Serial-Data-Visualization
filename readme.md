# CAN总线电机监控系统

## 项目结构
- can_simulator.py: CAN总线模拟器,负责模拟电机数据和故障
- can_monitor.py: 主监控界面,显示实时数据和曲线
- can_controller.py: 控制器界面,发送控制指令
- data_logger.py: 数据记录和回放功能
- utils/
  - constants.py: 常量定义
  - data_parser.py: 数据解析工具

## 功能特性
1. 实时数据采集与显示
   - 三相电流、电压监控
   - 转速、温度监控
   - 故障状态监控
   
2. 数据可视化
   - 实时波形图表
   - 历史数据趋势
   - 故障报警显示

3. 数据记录与回放
   - 数据本地存储
   - 历史数据回放
   - 数据导出功能

4. 电机控制
   - 启动/停止控制
   - 速度设定
   - 运行模式切换

5. 故障模拟
   - 过流保护
   - 过压保护
   - 过温保护
   - 堵转保护 

## 运行方式
   运行can_monitor.py
